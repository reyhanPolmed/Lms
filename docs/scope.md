# LMS Scope Guard

## In Scope
- Authentication and authorization
- User management
- Role management (`student`, `teacher`, `admin`)
- Student profile
- Teacher profile
- Class management
- Course management
- Enrollment
- Learning materials
- Assignments
- Assignment submissions
- Quizzes/exams
- Grades
- Attendance
- Announcements
- Basic dashboard summaries
- Notifications (only existing capability)

## Out of Scope
- Marketplace
- Payment gateway
- Social feed
- Complex gamification
- Video conferencing
- AI tutor
- Ecommerce
- Blog/CMS
- HR/payroll
